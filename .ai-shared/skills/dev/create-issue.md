# /create-issue — Capture a Standalone Issue

Write a specific title and body from the supplied problem, context, and expected outcome. Ask only for missing essentials, and apply requested labels and milestone. Create it with [dev-utils.sh](../../bin/dev-utils.sh) `issue-create <title> <body-file> [gh options]` under [plan.md — Git identity](plan.md#git-identity), then return its URL.
