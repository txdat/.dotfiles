# Development Skills

[PROCESS.md](../../PROCESS.md) owns the delivery policy and shared-rule directory. Load only the current skill and the references needed for the task.

| Need | Skill |
|---|---|
| Deliver or resume a feature/fix/refactor | [ship-feature](ship-feature.md) |
| Clarify or split an ambiguous requirement | [frame-goal](frame-goal.md) |
| Understand existing code | [explore](explore.md) |
| Plan application changes | [design-feature](design-feature.md) |
| Review a plan before approval | [review-feature](review-feature.md) |
| Implement an approved plan | [execute-feature](execute-feature.md) |
| Diagnose a bug and route its fix | [fix-bug](fix-bug.md) |
| Review implemented work | [review-code](review-code.md) |
| Publish reviewed PRs | [create-pr](create-pr.md) |
| Design/review system boundaries | [design-system](design-system.md), [review-system](review-system.md) |
| Design/review an infrastructure runbook | [design-infra](design-infra.md), [review-infra](review-infra.md) |
| Capture a standalone issue | [create-issue](create-issue.md) |
| Extract session lessons | [recap](recap.md) |

[frontend-design.md](frontend-design.md) supplies UI-specific guidance; [PROCESS.md — Repository conventions](../../PROCESS.md#repository-conventions) defines design notation. Delegated tasks use the same owning skill as direct work.
