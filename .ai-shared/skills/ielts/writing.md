# /ielts-writing — Plan, Review, or Practise

Read [README.md](README.md); use [rubric.md](rubric.md) for scoring or target-band advice.

## Choose the requested mode

A focused question gets focused feedback. Prompt-only input or an explicit planning request uses assistant mode. Prompt plus response uses review unless the learner requests otherwise. A practice request generates a complete original task and invites an attempt before revealing a sample.

## Assistant mode

Use the complete prompt and any supplied target band. If the prompt is missing, ask for it. If the target is missing or invalid, continue qualitative planning while clarifying it; do not assume the learner's level. Task 1 needs the actual visual or complete data.

Build a response plan covering every prompt obligation, each paragraph's purpose and development route, relevant target-band guidance, and likely task-specific errors. Scale detail to the request. Separate required coverage from optional development; preserve the learner's position or label a proposed position as a choice. Develop main points beyond topic labels with explanation, comparison, supplied detail, or a clearly illustrative example. Check coverage, support, and consistency with the supplied material.

When a target is supplied or requested, connect the plan to [rubric.md](rubric.md). Desired qualities are not evidence of current ability: a planned outline cannot establish a score. Half-band bridges are coaching, not separate official descriptors.

Task 2 follows its exact questions: both views means both; outweigh requires a justified comparison; causes, effects, and solutions are distinct obligations. Task 1 instead needs an accurate overview and grouped features, comparisons, stages, or map changes from supplied material. Do not invent data.

Planning notes may use bullets. [Academic Writing format](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing) sets minimum lengths of 150 words for Task 1 and 250 for Task 2 and connected-prose responses. Fixed paragraph counts, PEEL, complex language in every sentence, and invented statistics are not requirements. Supply a full illustrative response only when requested; practice tasks retain the attempt-first sequence.

## Review

Check the original's prompt coverage and word count. Apply the rubric independently of any rewrite. Locate useful corrections, explain their effect, and group repeated errors; distinguish optional alternatives. Tags may name the criterion and actual error, such as `off-topic`, `missing-overview`, `unclear-reference`, `collocation-error`, or `subject-verb-disagreement`. Common vocabulary is not itself an error.

Demonstrate revisions that preserve intended meaning. Identify added development and label illustrative examples; never fabricate personal facts. Choose a manageable revision exercise addressing the main limitation.

A full report includes assessable criterion estimates with evidence and uncertainty, located corrections, a revision or focused comparison, and the next exercise. Scoring limitations follow the rubric; saving follows README.
